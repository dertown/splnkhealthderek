About Splunk Health Derek+

Search-head only, built for Splunk Cloud Platform (Victoria and Classic) and Splunk Enterprise. Version 1.7.79.

Executive overview

What it does

The pages read _internal, _introspection and your event indexes, compare them with learned baselines, and list what needs a person. The Data Quality Agent proposes a fix and, when an AI provider is saved, asks that provider for a second opinion.

Recording a decision writes one row to the dq_agent_approvals KV Store. Asking the provider writes the reply to dq_agent_ai_suggestions. Neither path edits Splunk configuration, restarts a forwarder, or rotates a token.

Cloud notes

The AI connection test and the suggested fixes call the provider directly from the search head, so the search head needs outbound HTTPS to that provider. The API key lives in the KV Store collection dq_agent_ai_config, which is not shipped in the app package.

Install with sc_admin. The app ships with is_configured = 0 and every object grants sc_admin.
