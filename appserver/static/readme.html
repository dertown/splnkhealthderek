How to use Splunk Health Derek+

A search-head app for Splunk Cloud and Splunk Enterprise. It watches ingestion, hosts, HEC tokens, SC4S and Edge, and suggests fixes. A person approves or dismisses every suggestion. The app never changes Splunk configuration.

Working a suggestion

1. Filter the work queue if you want, or leave it on all.

2. Click a row. The saved AI provider is asked automatically and the suggested fix fills in below the playbook fix. Click the Fix cell to ask again.

3. Click Approve or Dismiss in the row. The row's status updates straight away and the decision is stored in the dq_agent_approvals KV Store. A decision closes a problem for 24 hours.

4. The sample config panel shows which file to change, where it goes, what differs on Splunk Cloud, and a command and search to check the fix. Nothing is applied for you.

Thresholds

All of these are search macros under Settings → Advanced search → Search macros.

exec_health_silence_sec 3600, seconds without data before DATA SILENT. exec_health_heartbeat_sec 600, seconds without _internal before a missing heartbeat, until that host has its own gap. exec_health_heartbeat_samples 48, gaps required across at least a day before the learned gap is used. exec_health_season_samples 6, days of the same hour required before that hour's ingest level is used. exec_health_latency_sec 300, p95 index lag before DELAYED. exec_health_sigma 2, standard deviations below a host's mean before ALERT. exec_health_hec_silence_min 5 and exec_health_hec_baseline_eps 100 control HEC silence.
