Feeds you expect

The last 30 days, compared with the list in lookups/feed_catalog.csv. Copy a row for each feed. Name the index, the sourcetype you expect, and how many minutes of silence count as a problem. Gone quiet means nothing arrived in that time. Wrong sourcetype means the data arrived, but not as the sourcetype you named. New this week means that source was first seen in the last 7 days. A row you mark as turned off on purpose stays on the list and is not counted.

Catch-all indexes

Where unexpected data is allowed to land. In the feed list, set that index's state to catchall. The name is whatever this stack uses. The starting list includes quarantine, lastchance, and main. Delete a row when that index is a normal place for data, especially main.
